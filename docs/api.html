pa'lante API v1 https://pa-lante-web.vercel.app

Infraestructura de datos financieros personales

El contexto financiero de una persona, legible por máquinas.

Pa'lante extrae el contexto financiero desde bancos, entidades y documentos, lo normaliza a un modelo único y lo entrega por HTTP y por MCP. Cada cifra llega con su procedencia, su método de cálculo y su nivel de confianza — nunca un número suelto.

Primera llamada
curl https://pa-lante-web.vercel.app/api/v1/perfil \
  -H "Authorization: Bearer palante_•••"

Autenticación

Bearer token sobre HTTPS. El token pertenece a una persona y se emite desde su propia cuenta: no hay claves de aplicación ni acceso sin dueño. 

Authorization: Bearer palante_a7Kd9mQ2xR4vB8nL3pW6

El valor en claro se muestra una sola vez, al generarlo. En base de datos vive únicamente su sha256. Cada llamada queda registrada con su token, su recurso y su resultado, y el dueño puede revocarlo en cualquier momento — la revocación es inmediata.

Todo acceso deja rastro.

No es telemetría: es la bitácora que la persona consulta para saber quién leyó sus datos financieros y cuándo. Es lo que hace defendible mover esta información.

Scopes

Cada token declara qué puede leer. Un token sin scopes explícitos sería un interruptor, no un permiso.

ScopeConcede
perfil:leerEl perfil financiero agregado
cobertura:leerQué fuentes están conectadas y qué cubren
hallazgos:leerHallazgos individuales con su procedencia
prueba:generarVistas de divulgación para un tercero
exportarLa totalidad de los datos en crudo

Un token al que le falta el scope recibe 403 con la cabecera WWW-Authenticate indicando cuál necesita, para que el cliente pueda pedirlo sin adivinar.

Anatomía de una métrica

Es la decisión de diseño que define esta API. Ninguna cifra viaja sola: cada una carga cómo se calculó y qué la respalda, para que un agente pueda decidir cuánto confiar en ella. 

{
  "valor": 3950000,
  "unidad": "COP",
  "confianza": 0.93,
  "metodo": "Mediana de ingresos
     mensuales observados.",
  "evidencia": [
    {
      "id": "tx-ingreso-2026-03",
      "fuente": "gmail:Nequi",
      "procedencia": "observado",
      "confianza": 0.94
    }
  ]
}
valor + unidadNunca un número sin unidad. Los montos son pesos colombianos enteros.
confianza0 a 1. Promedio ponderado de la evidencia que sostiene la cifra.
metodoCómo se calculó, en prosa. Si un agente cita la cifra, puede citar el método.
evidenciaReferencias auditables dentro de Pa'lante. Nunca el documento ni la transacción cruda.

Procedencia

ValorSignifica
declaradoLo dijo la persona
observadoVino de una fuente o documento
estimadoLo calculó el motor de análisis
confirmadoLa persona lo revisó y lo dio por bueno
Las fuentes que se contradicen no se fusionan.

Si la DIAN y un extracto reportan ingresos distintos, ambos hallazgos sobreviven como filas separadas. Promediarlos destruiría justo la información que necesitas para decidir a cuál creerle.

Perfil

El contrato canónico. Es general por diseño: no contiene nada de ningún caso de uso concreto, así que agregar uno nuevo nunca rompe a los consumidores existentes.

GET /api/v1/perfil perfil:leer

Foto agregada del contexto financiero, calculada al vuelo.

{
  "perfil": {
    "version": "1.0",
    "periodo": { "desde": "2026-03-05", "hasta": "2026-08-25", "mesesObservados": 6 },
    "ingresos":     { "declarado", "verificado", "porcentajeVerificado", "variacionMensual" },
    "flujo":        { "gastoMensualObservado", "flujoLibreObservado" },
    "obligaciones": { "deudaTotal", "cuotaMensual", "cargaFinanciera" },
    "patrimonio":   { "total", "porTipo" },
    "cobertura":    { "dominios", "fuentesConectadas", "porcentajeCubierto" },
    "calidadDatos": { "completitud", "confianza", "estadoPreparacion", "datosFaltantes", "advertencias" }
  }
}

// Cada hoja bajo ingresos/flujo/obligaciones/patrimonio
// es una métrica completa: valor, unidad, confianza, metodo, evidencia.
Lee calidadDatos antes de concluir.

completitud baja o advertencias no vacías significan que el perfil no alcanza para lo que ibas a afirmar. Dilo en vez de rellenar los huecos.

Cobertura

Qué tanto del contexto financiero está efectivamente capturado. Es la métrica que decide si vale la pena confiar en el resto.

GET /api/v1/cobertura cobertura:leer 
{
  "cobertura": {
    "porcentajeCubierto": 27,
    "fuentesConectadas": ["DIAN", "DataCrédito", "WhatsApp"],
    "dominios": [
      { "dominio": "income", "fuentes": ["DIAN"], "hallazgos": 2, "confianzaMedia": 0.91 }
    ]
  },
  "calidad_datos": { "completitud": 80, "estadoPreparacion": "listo_para_compartir" }
}

Los once dominios posibles son income · liability · asset · property · vehicle · credit_report · pension · tax_profile · company · fine · account.

Hallazgos

La capa cruda debajo del perfil. Cada hallazgo es lo que dijo una fuente, sin fusionar ni resolver contradicciones.

GET /api/v1/hallazgos hallazgos:leer
ParámetroTipoDescripción
tipostringFiltra por dominio
fuentestringFiltra por fuente
limiteint1–200, por defecto 50
desplazamientointPor defecto 0
 
curl "…/api/v1/hallazgos?tipo=income&limite=20" \
  -H "Authorization: Bearer palante_•••"

{

  "paginacion": { "total": 63, "limite": 20, "desplazamiento": 0, "hay_mas": true }
}

Pruebas de divulgación

Vistas mínimas derivadas del perfil, pensadas para entregar a un tercero sin entregarle la vida financiera completa de la persona.

POST /api/v1/pruebas/capacidad-pago prueba:generar

Agregados verificables para evaluar un arriendo. No devuelve transacciones, comercios, cuentas ni documentos. 

{
  "prueba": {
    "proposito": "evaluar_capacidad_arriendo",
    "ingresoMensualVerificado": 3950000,
    "porcentajeIngresoVerificado": 94.0,
    "variacionMensualIngreso": 6.2,
    "cargaFinanciera": 18.4,
    "relacionCanonIngreso": 32.9,
    "estadoPreparacion": "listo_para_compartir"
  },
  "limites": ["No constituye aprobación ni recomendación crediticia."]
}
Una prueba no aprueba nada.

Entrega evidencia agregada; la entidad que recibe conserva sus propias reglas de decisión y su responsabilidad sobre ellas.

Exportar

Si los datos son de la persona, tiene que poder llevárselos enteros — incluida la bitácora de quién los leyó.

GET /api/v1/exportar exportar

Errores

Una sola forma para toda la API. Ramifica por code; muestra detail a un humano. 

{
  "error": {
    "code": "forbidden",
    "detail": "Este token no tiene el scope 'hallazgos:leer'. Genera uno que lo incluya.",
    "scope_requerido": "hallazgos:leer",
    "request_id": "req_8f3a1c9b2e7d4a6f0b15"
  }
}
CodeHTTPCuándo
unauthorized401Token ausente, inválido, revocado o vencido
forbidden403Token válido sin el scope requerido
not_found404El recurso no existe
invalid_request422Parámetros mal formados
server_error500Falla nuestra

Toda respuesta incluye X-Request-Id. Cítalo al reportar un problema: es la llave para encontrar esa llamada exacta.

Servidor MCP

La misma información, hablando Model Context Protocol, para agentes que no van a escribir un cliente HTTP. 

// Claude Code
claude mcp add --transport http palante https://pa-lante-mcp.vercel.app/mcp \
  --header "Authorization: Bearer palante_•••"

// Claude Desktop — autenticación: Ninguno, y el token como encabezado
{
  "mcpServers": {
    "palante": {
      "command": "npx",
      "args": ["-y", "mcp-remote", "https://pa-lante-mcp.vercel.app/mcp",
               "--header", "Authorization: Bearer palante_•••"]
    }
  }
}
ToolDevuelve
obtener_perfil_financieroEl perfil canónico completo
obtener_prueba_capacidad_pagoLa vista de divulgación de arriendo

Transporte HTTP sin estado: cada petición trae su token y se atiende sola.

Límites

Lo que esta API deliberadamente no hace.

  • No aconseja. Entrega datos con su procedencia. El diagnóstico, el plan y la recomendación los construye quien consume — y responde por ellos.
  • No decide. Ninguna respuesta aprueba, rechaza ni califica a una persona.
  • No expone crudo por defecto. Documentos y transacciones originales quedan dentro; la evidencia viaja como referencia auditable.
  • Sin rate limiting todavía. No está implementado. No construyas asumiendo que te vamos a frenar.
  • Sin webhooks. El perfil se calcula al momento de pedirlo; hoy toca hacer polling.
